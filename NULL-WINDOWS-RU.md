# Windows 2.7.1 — исправление чтения переписки

Исправлена ошибка «Не удается преобразовать значение NULL в тип значения», появлявшаяся при открытии переписки.

В API поле callDuration равно null у текстовых сообщений, фотографий, голосовых сообщений и их правок. Windows 2.7.0 ожидала обязательное целое число, из-за чего разбор всего ответа прерывался. В 2.7.1 поле необязательное; длительность состоявшихся звонков по-прежнему отображается в секундах. Отсутствующее значение в карточке звонка отображается безопасно как 0:00.

Регрессионная проверка windows/test-api.ps1 пропускает JSON с формой ответа API через настоящий Api.Call и штатный десериализатор. Она воспроизводит исходную ошибку на 2.7.0, а на 2.7.1 проверяет обычные сообщения, фото, голосовые, принятые/пропущенные звонки, правки/удаления, курсоры, аватарки и старые ответы без новых полей. Проверка выполняется в GitHub Actions после сборки Windows. Используются вымышленные данные и обработчик HTTP в памяти.

Закройте прежнюю версию через значок «Рядом» возле часов → «Закрыть приложение», затем запустите Ryadom-Windows-2.7.1.exe с рабочего стола. Крестик основного окна скрывает приложение в трей.

Аккаунт и переписка сохраняются. Android, iPhone и сервер для этого исправления обновлять не требуется.
