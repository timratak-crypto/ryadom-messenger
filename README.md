# Рядом — исходный код мессенджера

Нативные приложения для Windows (.NET Framework 4.8), Android (8+) и iPhone (iOS 16+). Есть регистрация и вход по юзернейму и паролю, поиск пользователей, личные сообщения, фотографии, голосовые сообщения и голосовые звонки.

## Содержимое

- `windows/` — приложение Windows; версия 2.5.2 исправляет исчезновение окна звонка при ограничении частоты вызовов и добавляет повторный вызов с отсчётом.
- `android/` — Android 2.5.1 с обработкой эха и сервисом уведомлений.
- `ios/` — iPhone 2.5.0; IPA нужно подписать для своего устройства.
- `server-relay/` — шлюз HTTP API и сервер передачи звука WebSocket. Лимит вызовов: 12 попыток на аккаунт за скользящую минуту, с оставшимся временем ожидания в ответе.
- `.github/workflows/` — сборка EXE, APK и неподписанного IPA.

Публикуется проверенный снимок исходников. Рабочие аккаунты, сообщения и файлы пользователей не входят в репозиторий. Приватное приложение администратора и ключи подписи здесь отсутствуют.

## Сборка и проверки

Windows: установите .NET Framework 4.8 Developer Pack и Windows SDK, выполните `powershell -ExecutionPolicy Bypass -File windows/build.ps1`. Результат: `windows/build/Ryadom.exe`.

Проверка звонков Windows: `npm ci --prefix server-relay`, затем `powershell -ExecutionPolicy Bypass -File windows/test-calls.ps1`. Нужен Node.js 24. Проверки используют искусственный звук и не включают микрофон.

Android: Android SDK 35, JDK 17+, `bash android/build.sh`, либо Actions → Build Android APK → Run workflow. Результат: `android/build/Ryadom-Android.apk`. Самостоятельная сборка создаёт свой тестовый ключ. Она не обновляет поверх официального APK с другой подписью; ключ официальных сборок хранится отдельно. Этот публичный workflow не загружает и не сохраняет кеш официальной подписи.

iPhone: Xcode, `macos-15`, workflow Build iPhone IPA. Результат `Ryadom-unsigned.ipa` требует подписи, например через Sideloadly. Неподписанный IPA нельзя установить непосредственно.

Сервер и его тесты: `cd server-relay && npm ci && npm test`, запуск: `npm start`.

## Существующий сервер и ограничения

По умолчанию клиенты подключаются к `https://ryadom-family-chat.onrender.com`. Шлюз передаёт разрешённые запросы в существующий сервер Sites, где хранятся аккаунты и переписки. Публикуемый шлюз не является самостоятельной базой данных: реализация API Sites и конфигурация рабочей базы не входят в этот снимок. Для независимого развёртывания понадобится совместимый API и замена адресов клиента/шлюза.

HTTPS/WSS защищают соединения с сервером, сквозного шифрования пока нет. Разговоры не записываются сервером. Бесплатный Render может засыпать и имеет квоты. На iPhone фоновые APNs-уведомления и системные входящие звонки пока не реализованы; на Android работа в фоне зависит от разрешений и ограничений батареи.
