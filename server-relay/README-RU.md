# Новый адрес сервера «Рядом»

Этот сервис передаёт запросы `/api/v2` к серверу «Рядом»: регистрация и вход по юзернейму и паролю, поиск пользователей и личная переписка. Аккаунты, хеши паролей, сессии и сообщения хранятся в базе D1 существующего сервера Sites. Локальная файловая система Render для переписки не используется. Маршрут `/api/chat` сохранён для ранее установленных версий приложения.

## Размещение

1. Войти в Render через GitHub и разрешить доступ только к приватному репозиторию `timratak-crypto/ryadom-family-messenger`.
2. Создать Blueprint из `render.yaml`. В нём один Web Service с явно выбранным тарифом **Free**. Платные базы и диски не создаются.
3. Дождаться Live и открыть выданный Render HTTPS-адрес на iPhone **без VPN**. Должно появиться `ok: true` и сообщение о доступности сервера.
4. Адрес уже указан в приложениях версии 2.0. После обновления каждый человек создаёт свой аккаунт, затем ищет собеседника по юзернейму и нажимает «Написать». Приглашения и группы для этого не нужны. Пароли и токены нельзя публиковать в репозитории или логах.

Тариф Free останавливает сервис через 15 минут без запросов; первое подключение может занимать около минуты. При первом запуске откройте адрес сервера в Safari и дождитесь ответа, затем подключайтесь в приложении. Доступность домена из конкретной сети нужно проверить; размещение само по себе её не гарантирует.

Сервис не принимает произвольные URL, не следует перенаправлениям и не передаёт cookies/токены Sites. Пароль при входе и регистрации, токен аккаунта и сообщения отправляются только исходному серверу по HTTPS. Тексты запросов и заголовки авторизации не записываются в журналы приложения. Render и исходный сервер обрабатывают трафик чата; сквозного шифрования нет.

Локальная проверка: `node --test server.test.mjs`. Запуск: `node server.mjs` (порт из `PORT`, по умолчанию 10000).

Условия бесплатного тарифа: https://render.com/docs/free
